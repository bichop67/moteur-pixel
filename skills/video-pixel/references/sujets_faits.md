qu'elles sont postées sur les réseaux : ne jamais compter sur les fichiers du PC pour savoir si un sujet a déjà été traité.

- **Avant de choisir ou de proposer un sujet** : chercher ici (Grep sur un mot du sujet). Un sujet présent ne se refait pas.
- **Dès qu'une vidéo est finie** (étape « dossier du jour », section 3 du skill) : ajouter sa ligne ici, dans la même
  session, sans attendre la publication. Le prochain code libre = le plus grand numéro de ce tableau + 1.
- **Publié** : `oui (date)` quand l'utilisateur dit que c'est posté ou quand Claude l'a publié ; `?` = inconnu.
  Une vidéo « Publié : oui » peut être supprimée du PC sans rien perdre.
