Décisions religieuses : laver les pieds entiers, chevilles comprises = OBLIGATOIRE (Coran 5:6 ; an-Nawawi, Charh
Mouslim 3/127-128 : aucun avis contraire reconnu dans le consensus) → « lave tes talons » à l'impératif ; une partie
sèche = ablutions pas valables (consensus, an-Nawawi sur Mouslim 243 : « مَنْ تَرَكَ جُزْءًا يَسِيرًا مِمَّا يَجِبُ تَطْهِيرُهُ لَا
تَصِحُّ طَهَارَتُهُ وَهَذَا مُتَّفَقٌ عَلَيْهِ ») : la laver (ou tout refaire), puis prier ; le hadith permet les deux sens
(an-Nawawi : « مُحْتَمِلٌ لِلتَّتْمِيمِ وَالِاسْتِئْنَافِ ») ; si un long moment est passé, tout refaire chez les hanbalites (et
chez les malikites si on l'avait laissé exprès) → à l'écran « LAVE LA PARTIE SÈCHE (OU REFAIS TOUT), PUIS PRIE »
(jamais « ne prie pas ») ; l'avertissement est dit MOT POUR MOT (« Malheur aux talons… à cause du Feu ! ») : AUCUN « tu
iras en Enfer » ; « ويل » = perdition / châtiment (Ibn al-Athir) ; selon 'Iyad et Ibn al-Moulaqqin : le talon lui-même ou
son propriétaire à cause de sa négligence → l'image montre une lueur autour du talon, sans brûlure. « Il a crié »
(« نادى بأعلى صوته ») = Boukhari 163 ; les talons secs = Mouslim 241a (même Compagnon, même parole) : les deux sous la
même réplique. « Pas besoin de poncer » : conseil de Grand (ne pas exagérer, Abou Dawoud 96 et Nasa'i 140 dans la
description), séparé de toute source ; on ne dit JAMAIS « pas besoin de frotter » : passer la main (dalk) est obligatoire
chez les malikites, recommandé chez les autres → dans le remède, la main passe UNE fois sur le talon.
