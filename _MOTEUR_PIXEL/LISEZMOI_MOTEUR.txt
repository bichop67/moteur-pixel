MOTEUR PIXEL « DUO » — mode d'emploi (mis à jour le 31/10/2026)
====================================================================
Le moteur des Shorts « VALABLE OU PAS ? », agrandi pour servir à TOUTES les chaînes : n'importe quels personnages,
décors et habillages. Les vidéos VOP déjà livrées sortent toujours identiques au pixel près (test fait).

Voir les planches dans le dossier CATALOGUE : troupe.png, poses.png, visages.png, options.png, habits.png,
icones.png, animaux.png, decors_1.png … decors_5.png, et les vidéos « Demo moteur duo.mp4 », « Demo 2 - mise en scene.mp4 »,
« Demo 3 - nouveautes.mp4 » (ombres, lumière, gestes, bouche, regards, relief, animaux, nouveaux décors) et
« Exemple - scenario texte (vertical / 16-9).mp4 » (une scène écrite en texte, partie 9) et
« Demo 4 - dialogue vivant.mp4 » (champ / contre-champ et réactions de celui qui écoute, partie 14) et
« Pourquoi on est moche en photo.mp4 » (explications en images calées sur les mots, partie 15).

---------------

lieux.py              NOUVEAUX DÉCORS (57) + places conseillées des personnages (SPOTS)
objets.py             74 icônes (tableaux, bulles de pensée)
animaux.py            ANIMAUX : chat, chien, cheval, âne, chameau, mouton, chèvre, pigeon (partie 13)

kit.py                plans prêts à l'emploi + thèmes de chaîne + mode maquette (sans voix) + commandes de rendu

                      porte, pluie, neige, voitures, passants, feu, SMS, notifications, cartons, caméra (partie 8)
exemple_scene.py      une vraie scène complète, commentée (« Rentré trop tard »)

miniature.py          MINIATURE YouTube 1280x720 + couverture de Short 1080x1920, automatiques (partie 11)

demo_scenes.py        la démo de toutes les fonctions de mise en scène
demo_nouveautes.py    la démo des nouveautés (ombres, lumière, gestes, bouche, regards, relief, animaux, décors)
controle_vop.py       vérifie que les Shorts VOP n'ont pas changé après une modification du moteur
controle_video.py     contrôle d'une vidéo finie (durée, volume, trous de son, planche) + copie légère
voix.py               transcription des voix (faster-whisper) pour caler bouches et sous-titres
modele_duo.py         MODÈLE À COPIER pour chaque nouveau Short (exemple complet : « Pourquoi le ciel est bleu ? »)

catalogue.py          refait les planches : python catalogue.py tout
serie.py, vop06.py, vop_suite.py, textes_suite.py : les Shorts VOP (ne pas modifier)


2. FAIRE UN NOUVEAU SHORT (n'importe quelle chaîne)
--------------------------------------------------
1) Copier modele_duo.py (ex. info01.py). Remplir : CODE, TITRE (sans apostrophe), DOSSIER, THEME, les 2 personnages, REPLIQUES.
2) python info01.py sheet planche.png   -> planche de contrôle. Sans voix, c'est une MAQUETTE (durées estimées) : on règle
   la mise en scène avant de payer ElevenLabs.
3) python info01.py voix                -> les textes à générer : UNE génération par personnage, répliques séparées par
   [long pause]. Enregistrer CODE_NOM.mp3 dans le dossier voix (ex. INFO01_ADO.mp3, INFO01_PAPI.mp3).
4) python info01.py asr                 -> transcription (asr_CODE.json). Relancer sheet : tout se cale sur les vraies voix.
5) Rendu : python info01.py tout   (toutes les images sur plusieurs cœurs, en priorité basse : le PC reste fluide, puis le
   montage). L'ancienne méthode marche toujours : frames 0 4 / frames 1 4 … puis video.
6) Contrôle : 1 image par seconde (planche) + transcription de l'audio final, comme pour les VOP.
Règles de mouvement (voir mémoire) : glissés lents, fondus de 0,22 s, jamais de secousse ni de coupe sèche.


3. LES PLANS DU KIT (kit.py)
----------------------------
kit.accroche(["LIGNE 1", "LIGNE 2"], kit.photo("rue", "ADO", face="choc"), THEME)   carte d'accroche (0 à 1,85 s)
kit.duo_plan(t0, t1, "rue_nuit", "ADO", "PAPI", g=dict(pose=…, face=…), d=dict(…))   plan large, places conseillées du décor
kit.gros_plan(t0, t1, "ADO", "rue_nuit", face="choc", bulle="!" | "?" | "...", pensee="ampoule")   fond flou, respiration
kit.solo(t0, t1, "ADO", "parc", x=540)                                               un seul personnage
kit.marche(t0, t1, "ADA", "rue", 200, 860)                                          traverse le décor en marchant
kit.tableau_plan(t0, t1, kit.ecrit(lignes, icones, src="SRC …", style="craie"), gauche="ADO", droite="PAPI")
    lignes = [(y, "TEXTE", taille, accent?)] ; icônes = [("argent", x, y, échelle)] ; zone d'écriture x 22-248, y 68-252
    styles : craie (décor tableau), feutre (tableau_blanc), ecran (ecran_info), parchemin (tableau_parchemin)
kit.fin(t0, t1, "parc", "ADO", "PAPI", THEME)                                        rire + « ABONNE-TOI POUR LA SUITE »
Réglages d'un personnage dans un plan : pose, face, objet, assis=True, back=True (de dos), sweat (goutte), blush,
larmes, mute=True (ne parle pas), noblink. Dans un Shot : tags=[("texte", t_in, t_out)], src="SRC …".

8. MISE EN SCÈNE (scene.py) — de VRAIES scènes
----------------------------------------------
Démos : CATALOGUE/« Demo 2 - mise en scene.mp4 » (une fonction par chapitre, le nom de la commande à l'écran) et
« Exemple - scene complete.mp4 » (sketch « Rentré trop tard », script : exemple_scene.py, très commenté).
Un plan = une Scene. Les temps sont en secondes DANS le plan ; x, y = pieds du personnage en pixels écran (1080 x 1920).
  sc = scene.Scene(t0, t1, "cuisine_nuit")
  ado = sc.role("ADO", x=320)                 # aussi : place="gauche"/"droite", y=…, k=…, regard="gauche", pose=…, face=…
  maman = sc.role("MAMAN", x=780, meuble="chaise", regard="gauche")     # assise sur une chaise
  plan = sc.plan()                            # -> un plan comme les autres (à mettre dans la liste des plans)
Jouer (Role) :
  ado.a(2.0, pose="question", face="choc", objet="telephone")   change à l'instant 2,0 s (assis=True/False aussi)
  ado.entre(0.3, 2.3, depuis="gauche")         entre en marchant (bruit de pas discret) ; ado.sort(t0, t1, vers="droite")
  ado.marche(t0, t1, x, y)                     marche jusqu'à (x, y) ; ado.glisse(t0, t1, x, y) se déplace sans marcher
  ado.tourne(t) / ado.regarde(t, "gauche")    se retourne / regarde d'un côté
  ado.assoit(t) / ado.leve(t)                  s'assoit / se lève (mettre une chaise : sc.meuble("chaise", x))
  ado.cache() + ado.apparait(t0, t1)           invisible au début puis apparaît en fondu ; ado.disparait(t0, t1)
  ado.rit(t0, t1) / ado.sautille(t0, t1)      petits sauts doux ; ado.parle(t0, t1) : la bouche bouge sans voix
Objets et meubles :
  sc.donne(t0, t1, ado, maman, "sac_courses") l'objet passe de main en main (petite courbe)
  sc.meuble("chaise" | "tabouret" | "fauteuil" | "table" | "bureau" | "lampe" | "plante" | "tele", x, regard=…)
  sc.porte(410, 1272, t_ouvre=0.4, t_ferme=2.7)  porte qui s'ouvre (décor « entree » ou « entree_nuit »)
  sc.ecran(x0, y0, x1, y1)                     écran (télé, ordi) dont l'image change doucement
Réactions au-dessus de la tête : sc.effet(role, t0, t1, "coeurs" | "colere" | "idee" | "zzz" | "larmes" | "goutte" |
  "etoiles" | "notes" | "points" | "brille") ; sc.bulle(role, t0, t1, "!") ; sc.pensee(role, t0, t1, "batterie")
Décor vivant : sc.pluie(), sc.neige(), sc.feuilles(), sc.lucioles(), sc.oiseaux(), sc.voitures(phares=True),
  sc.passants(n=3), sc.vapeur(x, y), sc.feu(x, y), sc.clignote(x, y), sc.lumiere(t, "cuisine_nuit") (le décor change)
Son : sc.son(t, "dv_porte_bois", 0.15) ; sc.ambiance("amb_pluie", 0.6) — bruitages de _BRUITAGES, discrets sous la voix
Caméra : sc.camera([(0, 1.0, (540, 1080)), (3.0, 1.15, (420, 1040)), …]) glisse doucement de clé en clé ;
  sc.suit(D, "ADO", "MAMAN") dérive vers celui qui parle (lent : règle des mouvements doux)
Écran : sc.notification(t0, t1, "MAMAN", "Tu rentres ?") ; sc.texte(fonction) ; sc.legende("TITRE", "code")
Plans tout faits :
  scene.sms(t0, t1, "MAMAN", [(0.7, "lui", "T'es où ?"), (3.2, "moi", "J'arrive")], bg="chambre_ado", avatar="MAMAN")
  scene.carton(t0, t1, "LE LENDEMAIN…", sous="8 H 00")          carton de temps sur fond noir
  scene.epaule(t0, t1, "rue", "ADO", "PAPI")                     par-dessus l'épaule (ADO de dos au premier plan)
  scene.etablissement(t0, t1, "rue_nuit", cible=(300, 640))      plan d'ensemble : on s'approche lentement d'une fenêtre
Dialogue : kit.dialogue(voix, code, repliques, avant={0: 7.6, 3: 3.2}) laisse des silences (plans muets, SMS) ;
  kit.allonge(D, 1.8) rallonge la fin.
Nouveaux décors : entree (+ _nuit : entrée d'appartement avec porte animée), noir (cartons).


9. ÉCRIRE UNE SCÈNE EN TEXTE (scenario.py) — la vidéo se fait toute seule
------------------------------------------------------------------------
Exemple complet : scenarios\le_passeport_de_papi.txt (vidéo : CATALOGUE\Exemple - scenario texte (vertical).mp4).
  python scenario.py scenarios\mon_sketch.txt sheet     planche de contrôle (sans voix : MAQUETTE, durées estimées)
  python scenario.py scenarios\mon_sketch.txt voix      textes à donner à ElevenLabs (une génération par personnage)
  python scenario.py scenarios\mon_sketch.txt asr       transcription, une fois les MP3 posés dans le dossier voix
  python scenario.py scenarios\mon_sketch.txt tout      la vidéo (MP4 à côté du fichier texte)
  python miniature.py scenarios\mon_sketch.txt          la miniature YouTube + la couverture du Short
Le fichier (une ligne = une chose ; # = commentaire) :
  TITRE: Le passeport de Papi        THEME: sketch (ou valable, info, histoire, mystere, science, argent, podcast, neutre)
  FORMAT: vertical | horizontal       MUSIQUE: fond_espoir (ou aucune)       PERSONNAGES: ADA, PAPI (1er à gauche, 2e à droite)
  MINIATURE: SON PASSEPORT / EST OÙ ?!    ICONE: question     (facultatif : texte et icône de la miniature)
  DEMO: oui                          (facultatif) affiche le code de chaque schéma quand il apparaît (pour apprendre)
  VOIX: dossier des MP3 (sinon « voix_CODE » à côté du fichier)        CODE: nom court des fichiers voix
  == aeroport, passants, 1.2s        un DÉCOR + options : pluie, neige, feuilles, lucioles, voitures, passants, foule, oiseaux,
                                     feu, 2s (plan muet au début), ensemble (540, 700) (la caméra s'approche de ce point),
                                     texte "23 H 47" (grand texte au début du décor)
  ADA entre à gauche, téléphone      une ACTION, au moment où elle est écrite dans le récit
  ADA (choc, bulle !) : Comment ?!   une RÉPLIQUE ; entre parenthèses, ce qu'il fait en la disant
  G : Le miroir {miroir ADA} t'inverse.   un SCHÉMA qui apparaît pile sur ce mot (partie 15 ; pas dit, pas sous-titré)
  SMS MAMAN : Tu es où ? / > J'arrive        écran de téléphone (« > » = message envoyé)
  NOTIF MAMAN : Tu rentres quand ?   notification en haut pendant la réplique suivante
  CARTON : LE LENDEMAIN / 8 H 00     carton de temps         FIN : tout le monde rit + « abonne-toi » (2,6 s)
  LEGENDE : TITRE / texte            légende de démonstration en haut (le dernier « / » sépare le titre du texte)
Mots compris entre parenthèses (accents et majuscules sans importance) :
  visages : content, sourit, rit, choc, surpris, gêné, malin, blasé, énervé, en colère, crie, triste, pleure, peur, suspect,
            dégoûté, clin d'oeil, amoureux, émerveillé, dort, fier, calme, honteux / regarde en bas
  gestes : explique, pointe, index, question, panique, bras croisés, salue, pouce, mains sur les hanches, facepalm,
           réfléchit, hausse les épaules, victoire, au téléphone, tape, stop, présente, invoque, prie, boit
           (un geste dure le temps de la réplique, puis le perso revient au repos tout seul)
  effets : coeurs, colère, idée, zzz, larmes, goutte (transpire), étoiles, notes (chante), points, brille
  objets : téléphone, livre, tasse, passeport, valise… ; « tient le livre », « donne le passeport à PAPI », « range »
  mouvements : entre (à gauche / à droite / par la porte), sort (à gauche / à droite), s'approche, se retourne, apparaît,
               assis (une chaise est posée), se lève, sautille
  bulles et pensées : bulle ! / bulle ? / bulle … ; pense à batterie (n'importe quelle icône du catalogue)
  plans : gros plan (plan serré pendant la réplique), plan moyen, plan large, épaule (champ / contre-champ forcé)
  option de décor « serre » : plan à deux serré (on voit les deux visages, pas de champ / contre-champ)
CHOIX AUTOMATIQUE DES PLANS (toujours des glissements doux, jamais de secousse) : plan d'ensemble qui se resserre au début
  d'un décor ; la caméra glisse un peu vers celui qui parle ; elle se rapproche sur les répliques fortes (choc, cri, peur,
  colère, larmes, bulle « ! ») et sur la chute avant FIN ; les autres regardent celui qui parle et RÉAGISSENT (partie 14) ;
  CHAMP / CONTRE-CHAMP : quand les persos se répondent, la réplique est filmée par-dessus l'épaule de celui qui écoute
  (2 d'affilée au plus, puis on revient au plan large ; jamais pour la 1re réplique d'un décor, la chute, un perso assis
  ou qui marche) ; les SMS, cartons et gros plans coupent la scène en fondu, puis on y revient là où on en était.
Un mot inconnu est signalé (« je ne connais pas … ») et ignoré ; un décor ou un personnage inconnu arrête tout avec la liste.


10. FORMAT HORIZONTAL 16:9 (vidéos longues, 1920x1080)
------------------------------------------------------
Même script, une seule ligne change : THEME = pxv.Theme(…, format="paysage") (ou « FORMAT: horizontal » dans un scénario).
Les décors sont redessinés plus larges (pas de miroir ni de doublon), les persos gardent leurs places, la caméra, les
sous-titres, le bandeau, les SMS et les cartons s'adaptent. Exemple : CATALOGUE\Exemple - scenario texte (16-9).mp4.


11. MINIATURES AUTOMATIQUES (miniature.py)
------------------------------------------
python miniature.py scenarios\mon_sketch.txt → « … - miniature.jpg » (YouTube 1280x720) et « … - couverture short.jpg »
(1080x1920) : décor flou, persos en grand avec contour blanc et leur émotion la plus forte du scénario, titre en grosses

  {compare ADA}                    miroir + photo + flèche « INVERSÉ »

  {efface}                         tout part en fondu (on recommence)          {fond tableau}  autre fond pour le schéma
Didascalie « schéma » : la réplique reste sur le schéma sans nouvel élément. Une balise en fin de phrase apparaît sur le

29. BRIQUES RÉUTILISABLES ET COMMANDES DE LOT (briques.py, lot.py, sources.py — 09/11/2026)
Pourquoi : le lot du 08/11 (9 Shorts) a coûté ≈ 1,6 milliard de tokens, surtout parce que chaque Short avait son
  animation sur mesure (≈ 50 Ko de code, 17 fichiers explique_0*.py = 866 Ko). Depuis le 09/11, un nouveau sujet se
  règle depuis le scénario avec 8 briques ; le sur-mesure est réservé à l'accroche, avec l'accord de l'utilisateur.
Briques (détail des options : en-tête de briques.py ; démo : scenarios\demo_9_briques.txt) :
  {liste …} lignes au tableau, barrées / cochées / en or        {citation …} parole citée dans un cadre doré
  {jauge …} tube qui monte ou descend, visage qui suit          {focus …} gros plan sur un objet, endroit entouré
  {versus …} deux cartes, la mauvaise et la bonne               {bulles …} formules qui se répondent
  {trajet …} route entre deux endroits, étapes                  {grille …} N cases à cocher ou barrer
  + {<brique> lueur rouge|or|vert|bleu|fin} sur toutes.
  La 1re balise crée la brique, les suivantes ({brique action …}) la font évoluer ; après un retour à la scène elle
  reprend où elle en était (briques._MEMO). Branchement : explique.CLES_BRIQUES → briques.ordre / briques.fin_anim.
  Nouvel objet pour focus / versus / trajet : fonction décorée @objet("nom") dans briques.py.
Commandes :
  python lot.py verifie | planches | voix | rendu | controle  scenarios\islam_3*.txt

      figé modifié ; planches : + une image « … - controle.png » par Short (5 premières secondes à 2 images / s, puis
      1 image / s) ; voix : coût, textes dans un seul fichier, textes figés (scenarios\_textes_figes.json) ; rendu :
      ancienne version gardée en (vN), rendu, contrôle final, copie légère.
