# ISLAMARCADE — Short 4 : « Allah l'a pardonné pour une branche ?! » — 30 s maximum
# Version du 01/11/2026 (l'ancienne « Il a pousse une branche » est dans le zip du moteur) : accroche choc dite par
# GRAND, pas de « 1/2 » à l'écran, histoire MONTRÉE de près (la branche d'épines en travers du chemin, la lumière quand
# Allah lui pardonne) et aujourd'hui : une grand-mère qui ne peut pas passer, PETIT dégage la trottinette, elle passe.
# Sources vérifiées sur sunnah.com le 01/11/2026 : Boukhari 652 (« فشكر الله له فغفر له ») ; Boukhari 2989
# (« ويميط الأذى عن الطريق صدقة »). L'homme de l'histoire est anonyme (ni prophète ni Compagnon) : on peut le dessiner.
# Pas de pardon « garanti » (c'est une cause de pardon : HadeethEnc) → « elle pouvait te faire pardonner » ;
# الأذى = ce qui peut blesser. Relecture du 01/11/2026 : « si c'est sincère » à l'écran (Ibn Taymiyya, Minhaj
# as-Sunna : il a été pardonné pour la foi sincère qui l'animait ; Mouslim 1914c ; Coran 4:114).
# Décor rue_proche : la rue à l'échelle des persos (dans « rue », ils faisaient trois étages de haut).
# Voix : GRAND = accroche neuve + ses 4 autres répliques déjà enregistrées (ISL4) ; PETIT = « Pardonné ? Pour une
# trottinette ?! » (ISL4).
