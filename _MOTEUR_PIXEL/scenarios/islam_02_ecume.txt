# ISLAMARCADE — Short 2 : « Tes péchés effacés en 2 minutes ?! » (Subhan Allah wa bihamdih × 100) — 30 s maximum
# Version du 01/11/2026 (l'ancienne « Tes peches comme l ecume de la mer » est dans le zip du moteur) : accroche choc,
# pas de « 1/2 » à l'écran, et l'écume MONTRÉE (demande de l'utilisateur) : ses péchés = de l'écume sale autour de lui,
# puis sur le rivage chaque paquet d'écume sale (un petit péché) est lavé UN PAR UN par les vagues ; le rocher des
# grands péchés reste (il faut s'en repentir).
# Sources vérifiées le 01/11/2026 : Boukhari 6405 (et Mouslim 2691) sur sunnah.com ;
# HadeethEnc n° 5516 : il s'agit des petits péchés, les grands demandent le repentir — avis de la MAJORITÉ
# (Ibn Rajab rapporte un désaccord : Ibn Hazm et d'autres ; il retient l'avis de la majorité).
# « ≈ 2 à 3 minutes » = estimation (le dhikr doit être prononcé), affichée comme telle. Relecture du 01/11/2026 :
# l'avis majoritaire s'appuie sur Mouslim 233 (« tant que les grands péchés sont évités ») → source à l'écran ;
# le rocher des grands péchés est visible dès le début (le rivage propre ne veut pas dire « tout est effacé »).
# Voix : PETIT = accroche neuve + ses 2 répliques déjà enregistrées (ISL2) ; GRAND = ISL2 tel quel.

GRAND (explique) : Le Prophète ﷺ a dit : {ecume "TES PÉCHÉS" sale} tes péchés sont {vague} effacés… même s'ils sont comme *l'écume de la mer*. {source "BOUKHARI 6405"}
GRAND (index, schéma) : Pour la plupart des savants : les {propre "PETITS PÉCHÉS : EFFACÉS"} *petits* péchés. Les {rocher "GRANDS PÉCHÉS"} grands, il faut s'en {rocher "IL FAUT SE REPENTIR"} repentir. {source "AVIS MAJORITAIRE · CF. MOUSLIM 233"}
PETIT (content, pouce) : Je commence *maintenant* !
