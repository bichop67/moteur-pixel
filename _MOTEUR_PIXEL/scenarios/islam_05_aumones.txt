# ISLAMARCADE — Short duo « Tu dois 360 aumônes chaque matin ?! » — 30 s maximum (03/11/2026)
# Modèle : « Tes péchés effacés en 2 minutes ?! » (le duo qui a le mieux marché sur TikTok : 16 k vues, 24,7 % jusqu'au
# bout, 866 enregistrements) : grosse récompense pour un petit geste, montrée au sens propre.
# Image 0 = la radiographie de Petit (sa casquette passe aux rayons X), ses articulations rouges qui battent, « 0 / 360 ».
# Sources vérifiées sur sunnah.com le 03/11/2026 :
#   Mouslim 720 (Abou Dharr) : chaque matin, une aumône est due pour chaque articulation ; chaque tasbih, tahmid, tahlil,
#   takbir est une aumône ; deux rakats de Duha suffisent pour tout cela (يجزئ من ذلك ركعتان يركعهما من الضحى) ;
#   Mouslim 1007a (Aïcha) : l'être humain a été créé avec 360 articulations ;
#   Abou Dawoud 5242 (Bourayda), sahih selon al-Albani : 360 articulations, une aumône pour chacune, « qui en est
#   capable ? »… « deux rakats de Duha te suffisent ».
# Relecture indépendante du 03/11/2026 : « tu dois » est fidèle (فعليه أن يتصدق), mais les savants y voient une forte
# recommandation (Ibn Hajar, Fath 3/308 ; Ibn Rajab, Jami' al-'Ulum, hadith 26) → « une sunna » dans la voix et
# « SUNNA · PAS OBLIGATOIRE » à l'écran ; horaire de Douha corrigé : d'un quart d'heure après le lever du soleil à
# 10 min avant Dhohr (Ibn 'Uthaymin, ach-Charh al-Mumti' 4/122 ; IslamQA 22389) — « après le lever » faisait prier
# pendant un moment interdit (Mouslim 831). Un « +1 » par dhikr : exact (« فكل تسبيحة صدقة ») ; Douha couvre les 360
# d'un coup (Ibn Rajab : la prière fait travailler tous les membres). Orthographe pour la voix : « Douha », « Soubhan ».
